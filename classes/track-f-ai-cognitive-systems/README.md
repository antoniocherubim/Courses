# Track F — AI & Cognitive Systems

[← Mapa geral](../README.md)

## Regra metodológica

Distinguir sempre:

```text
mecanismo implementado
evidência empírica
modelo matemático
hipótese cognitiva
metáfora
```

Isso é especialmente importante quando conceitos de neurociência, cognição e sistemas de IA são comparados.
