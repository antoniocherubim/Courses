# Roadmap — Personal Knowledge Roadmap

[← Courses](../README.md) · [Classes](../classes/) · [Maps](../maps/)

Este roadmap não é uma agenda rígida e não representa uma tentativa de estudar tudo simultaneamente.

Ele mantém uma **visão de longo prazo** enquanto o trabalho cotidiano permanece pequeno e executável.

---

## Estados

```text
✅ consolidado / material estruturado
🟡 em estudo ativo
🧭 conhecimento parcial; externalizar ou aprofundar futuramente
⬜ lacuna / ainda não estruturado
```

# Critério de prioridade

Antes de iniciar uma nova masterclass, perguntar:

1. Isso resolve uma lacuna que bloqueia algo atual?
2. Isso consolida conhecimento que já existe, mas está fragmentado?
3. Isso conecta dois ou mais blocos importantes do mapa?
4. Existe razão prática, acadêmica ou de projeto para estudá-lo agora?

Se nenhuma resposta for "sim", o tópico permanece no roadmap.
